# Product and deployment portfolio

These projects explore how to turn an operational or research workflow into software with explicit rules, human controls, and testable behavior. I define the product direction and use AI coding assistance to implement and evaluate the prototypes while developing my technical skills.

## Start with Dockflow

**A public inbound operations simulator.** Inspect a trailer's urgency, identify a compatible empty door, approve a simulated assignment, and undo it. The case study explains how occupancy, data freshness, and human judgment shape the workflow.

[Try the demo](https://dockflow-inbound-lab-olami-1110.boileditem.chatgpt.site) · [Read the case study](dockflow.md) · [Explore the code](../dockflow)

All facility data and operating policies are fictional. This independently written portfolio rebuild is separate from original workplace tools and their outcomes.

## Explore Echo

**A WhatsApp research interviewer prototype.** Researchers approve an interview pathway; the application controls consent, state, and follow-up limits while a model supplies structured analysis. The case study explains the product requirements and remaining real-device validation.

[Read the case study](echo.md) · [Explore the code and local setup](../README.md#echo) · [Review verification](../docs/VERIFICATION.md)

The source and automated application checks are available. A real WhatsApp voice interview, live transcription quality, hosted researcher access, and commercial platform eligibility have not been verified.
